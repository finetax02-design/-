# 위하고 화면 녹화 방법

위하고 화면의 어느 칸이 무엇인지 알아야 자동화 코드를 쓸 수 있다.
Playwright 의 녹화 기능으로, 평소처럼 한 번 작업하는 것만으로 그 정보를 얻는다.

## 순서

이 폴더의 파일을 번호 순서대로 더블클릭한다.

| 파일 | 하는 일 | 소요 |
|---|---|---|
| `1_설치.bat` | Playwright 와 브라우저 설치 | 5분, 최초 1회 |
| `2_로그인.bat` | 위하고 로그인 (세션 저장) | 1분, 최초 1회 |
| `3_녹화.bat` | 화면 조작 녹화 | 5분 |

## 왜 로그인을 따로 하는가

`2_로그인.bat` 에서 미리 로그인해두면, 녹화할 때는 이미 로그인된 상태로
시작하므로 아이디와 비밀번호를 칠 일이 없다.
따라서 **비밀번호가 녹화 파일에 들어가지 않는다.**

로그인 정보는 이 폴더 안의 `프로필` 폴더에만 저장된다.
`프로필` 폴더는 절대 다른 곳에 보내지 않는다 (`.gitignore` 에 등록되어 있다).

## 녹화할 때 해야 할 네 가지

브라우저와 함께 녹화 창이 열린다. 브라우저에서 아래를 한 번씩만 한다.

1. **전자세금계산서 화면으로 이동** — 메뉴를 어떻게 타고 들어가는지
2. **조회 조건 설정** — 기간, 구분(매입/매출), 전표상태 를 고르고 조회 클릭
3. **계정과목 입력** — 미추천 건 하나를 골라 차변계정을 입력하는 전 과정
4. **공제구분 변경과 전송** — 과세를 불공으로 바꾸고, 전송(확정) 까지

천천히 해도 된다. 녹화는 시간이 아니라 동작을 기록한다.
중간에 잘못 눌러도 상관없다. 다시 제대로 하면 된다.

끝나면 브라우저를 닫는다. 이 폴더에 `녹화결과.py` 가 생긴다.

## 보내기 전 확인

`녹화결과.py` 를 메모장으로 열어 훑어본다.
혹시 비밀번호처럼 보이는 문자열이 있으면 지우고 보낸다.

이런 줄이 있으면 안 된다:

```python
page.get_by_role("textbox", name="비밀번호").fill("실제비밀번호")
```

있다면 따옴표 안의 내용만 `<<비밀번호>>` 로 바꾼다.
`2_로그인.bat` 을 먼저 했다면 이런 줄은 나오지 않는다.

## 녹화가 비어 있을 때

`녹화결과.py` 에 `page.goto` 와 `page.close` 만 있고 클릭 기록이 없다면
Playwright 가 브라우저 제어권을 잃은 것이다. 흔한 원인 순서대로:

1. **크롬이 이미 실행 중이었다** — 가장 흔하다.
   `--channel chrome` 으로 띄울 때 크롬이 켜져 있으면 새 창이 기존 크롬 프로세스에
   붙어버려 Playwright 가 아무것도 기록하지 못한다.
   크롬을 전부 닫고 다시 하거나, `--channel chrome` 없이 (Playwright 전용 브라우저로) 한다.
2. **작업 전에 브라우저를 닫았다** — 녹화는 브라우저를 닫는 순간 저장된다.
   그 전까지의 동작만 기록되므로 할 일을 다 마친 뒤에 닫아야 한다.
3. **로그인이 안 된 상태였다** — 주소가 `/landing/ko/home/` 이면 로그아웃 상태다.

`0_점검.bat` 으로 현재 상태를 먼저 확인한다.

녹화 중에는 **Playwright Inspector 창에 코드가 한 줄씩 쌓이는지** 봐야 한다.
쌓이지 않으면 그 시점에 이미 제어권이 없는 것이므로 계속해도 소용없다.

## 안 될 때

- `python` 을 못 찾는다고 나오면 Python 이 PATH 에 없는 것이다. 그 메시지를 알려주면 된다.
- `--channel chrome` 에서 오류가 나면 크롬이 없는 것이다. `3_녹화.bat` 을 메모장으로 열어
  `--channel chrome` 을 지우면 Playwright 가 가진 브라우저로 실행된다.
- 위하고 주소가 다르면 브라우저 주소창에 직접 입력해도 된다. 녹화는 계속된다.
